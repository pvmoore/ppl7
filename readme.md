# PPL7 - Yellowhammer

A prototype programming language.

![Logo](/resources/images/logo.png)

It utilizes the D programming language for implementation and LLVM 22 for code generation. 

## Requirements

- [D Language](https://dlang.org/)
- [LLVM](https://llvm.org/)
